# KijaniKiosk

## Week 3: Production Server Foundation

This repository contains the KijaniKiosk Week 3 DevOps project.

The project focuses on:
- Auditing the existing server before making changes.
- Developing an idempotent server provisioning script.
- Configuring and securing systemd services.
- Managing logs, permissions, and firewall rules.
- Hardening the payments service.
- Documenting security decisions and verification results.

## Git Workflow

- main: primary branch.
- develop: integration branch.
- feature/week3-production-foundation: Week 3 implementation branch.
